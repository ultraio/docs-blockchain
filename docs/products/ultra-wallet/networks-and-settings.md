# Networks and settings

The Ultra Wallet 2.x **Menu** is the central place to switch networks, manage the apps you've connected to, and configure how the wallet behaves.

## Networks

The wallet ships with the built-in Ultra networks (such as Mainnet and Testnet). Open **Networks** from the menu to see the available networks, with the active one highlighted, and switch with a single tap.

![](/images/wallet-2x-networks.png)

### Custom networks

You can also point the wallet at your own RPC endpoint — for example, a local node or a private network.

1. From **Networks**, choose to add a custom network.
2. Enter a **name** and a **node URL**, then save.

![](/images/wallet-2x-custom-network.png)

Custom networks can be edited or deleted later from the same screen.

## Connected apps

When you connect the wallet to a decentralized application, that app's origin is remembered so you don't have to approve it every time. Open **Connected Sites** from the menu to review every site you've connected to.

![](/images/wallet-2x-connected-apps.png)

From here you can:

-   **Disconnect a single site** — revoke a site's access with the trash icon next to it.
-   **Disconnect All** — revoke access for every connected site at once.

The wallet's home screen also shows a connection bar for the site in your active browser tab, with a quick way to disconnect it.

## Side panel mode

The wallet can run as a regular popup or as a Chrome **side panel** that stays open alongside the page you're working on. Toggle between the two modes from the menu.

![](/images/wallet-2x-side-panel.png)

## Auto-lock

For security, the wallet locks itself after a period of inactivity. Use the **auto-lock** setting in the menu to choose how long the wallet stays unlocked before requiring your password again.

## Change password

Use **Change password** from the menu to set a new vault password. You'll be asked for your current password followed by the new one.

## Reset wallet

If you need to start over — for example, to restore from different keys — use **Reset wallet**. This is a destructive action that wipes the entire vault and every stored key, so it uses a hold-to-confirm control to prevent accidents.

> **Warning:** Resetting the wallet permanently deletes all stored keys from this device and cannot be undone. Make sure you have your private keys backed up before resetting.
